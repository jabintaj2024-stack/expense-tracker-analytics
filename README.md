# Expense Tracker Analytics Dashboard

## Project Overview

Expense Tracker Analytics Dashboard is a full-stack web application that allows users to manage daily expenses and visualize spending patterns through analytics.

## Features

* Add Expense
* View Expenses
* Delete Expense
* Total Expense Dashboard
* Highest Expense Tracking
* Total Transactions Counter
* Category-wise Analytics
* Pie Chart Visualization
* Search Expenses
* Filter by Category
* MySQL Database Integration

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MySQL
* Chart.js

## Database

Database Name:
expense_tracker

Table:
expenses

## Run Project

Install dependencies:

npm install

Start server:

npm run dev

Open:

http://localhost:3000
